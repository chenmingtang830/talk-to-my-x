# memory/ (Phase 1.5 scaffold)

Lightweight, **manually curated** prefs. The room does **not** auto-update these
after a call. See `references/local-layout.md`.

| File | Role |
| --- | --- |
| `USER.md` | Who the listener is; durable prefs |
| `TASTE.md` | Voice, depth, cite / recap style |

The brief / Synthesize recipes **may read** these when present. Bundle import
can overwrite `TASTE.md` (keeps a `.bak`).

Do not put secrets here. Prefer short bullets — full transcripts live in
`sessions/`.
