# Product definition

[//]: # (ob:08dab267)
## Problem

[//]: # (ob:fe04f9b3)
X reading happens in fragmented pockets. A post sparks a question or beginning
of a take, but that initial reaction is often gone by the time the user writes.
Existing feeds optimize consumption; generic summarizers discard the user's
specific taste and thinking.

[//]: # (ob:83cc85c8)
## Product

[//]: # (ob:ee157b17)
Talk to My X is a local-first Codex plugin for speaking with and acting on a
personal X account. GPT-Live owns speech, Codex owns conversation and tool use,
official X tools own X access, and the plugin owns only inspectable local state.

[//]: # (ob:63dcd89a)
The immediate output is a useful selection, reaction, draft, or confirmed X
action. The compounding asset is evidence-backed Taste and Voice memory.

[//]: # (ob:032631e8)
## Principles

[//]: # (ob:5fa1b1fc)
1. The feed is input; the user's reaction is the material.
2. Explain why a source matters to this particular user.
3. Preserve raw wording and source URLs before interpretation.
4. Let conversation perform the organization work.
5. Keep memory local, inspectable, evidenced, and reversible.
6. Voice is an interface supplied by the host, not a runtime we own.
7. External writes require exact preview and current action-specific approval.

[//]: # (ob:eabf1755)
## v0.1 boundary

[//]: # (ob:1c5ef6f8)
Codex on Mac and iPhone Remote are the only supported hosts. Users bring their
own X Developer App, API credits, and xurl OAuth. The product does not provide
cloud sync, hosted authentication, browser scraping, automation, or automatic
publishing.
